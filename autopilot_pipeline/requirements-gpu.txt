# requirements-gpu.txt — Kaggle T4 x2 GPU-specific packages
#
# Install AFTER requirements.txt:
#   pip install -r requirements-gpu.txt
#
# VRAM budget on Kaggle 2x T4 (15.6 GB each, 31.2 GB total):
#   GPU 0 (cuda:0): Chatterbox TTS       ~2.0 GB  (cleared after each scene)
#                   OR CogVideoX (mirror strategy)
#   GPU 1 (cuda:1): CogVideoX-2B         ~9 GB peak (NF4 T5 + fp16 Transformer)
#   ────────────────────────────────────────────────────────────────
#   CogVideoX memory breakdown:
#     T5 text encoder (NF4):   ~2.1 GB  (was 9.5 GB fp16 — saves 7.4 GB!)
#     Transformer (fp16):      ~4.0 GB
#     VAE + peak activations:  ~3.0 GB
#     Total peak:              ~9 GB  ✓
#
# CRITICAL: T4 (Turing) does NOT natively support bfloat16 — it is emulated.
#           All models loaded in torch.float16 for real T4 speed.
#
# VIDEO MODEL DISK USAGE (downloaded to Kaggle /root/.cache):
#   CogVideoX-2B:   ~5 GB  (primary)
#   LTX-Video:      ~9 GB  (fast fallback — loads ONLY if CogVideoX fails)
#   Do NOT preload both simultaneously — Kaggle disk limit is ~57 GB.
# ─────────────────────────────────────────────────────────────────────────────
