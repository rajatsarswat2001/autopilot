# requirements-gpu.txt
# Kaggle T4 GPU-specific packages
# Install AFTER requirements.txt
#
# VRAM BUDGET — Dual T4 (15.36 GB each):
#
#   cuda:0  Chatterbox TTS during audio phase    ~2.0 GB
#           (evicted before visual generation begins)
#
#   cuda:0  Wan2.1 T2V-1.3B during visual phase  ~8.2 GB active
#           (no group offloading needed — fits cleanly with 7 GB headroom)
#
#   cuda:0  LTX-Video I2V fallback               ~9-10 GB with group offloading
#           (only loaded if Wan2.1 fails; Wan is evicted first)
#
#   cuda:0  CogVideoX-2B last resort             ~10-11 GB with group offloading
#           (only loaded if both Wan and LTX fail)
#
# MODEL DISK USAGE (/root/.cache on Kaggle, ~57 GB limit):
#   Wan2.1 T2V-1.3B:  ~3 GB   (primary — always downloaded)
#   LTX-Video:        ~9 GB   (fallback — downloaded on first failure)
#   CogVideoX-2B:     ~5 GB   (last resort — downloaded on second failure)
#   Total worst case: ~17 GB  — well within Kaggle disk limit
#
# CRITICAL — T4 precision rules:
#   T4 (Turing sm_75) has NO native bfloat16 support.
#   bfloat16 on T4 triggers slow software emulation (~4x slower).
#   All models MUST load in torch.float16.
#   LTX VAE decode patched to float32 to prevent NaN black frames.
#   Wan2.1 VAE is stable in float16 natively — no patch needed.
#
# REMOVED vs v1:
#   bitsandbytes    — no longer needed (Wan2.1 fits T4 without NF4 quantization)
#   torchao         — removed (caused crashes, never needed for Wan2.1)
#   mirror strategy — removed (Wan2.1 is single-model; parallel pair gen
#                     gives no benefit vs sequential on one T4)
